# Database Schema - Wheat Assistance Workflow CSI

Data store: Google Sheets.
Source: n8n Google Sheets nodes in `Wheat Assistance Workflow CSI - v4.json`.

The workflow references these sheets:

- `Plant`
- `Plant_Price`
- `Users`

The original workflow docs also mention `Price_History`; keep it if you split daily historical price records from the latest price sheet.

## Sheet: `Plant`

| Column | Type | Notes |
| --- | --- | --- |
| `plant_id` | String | Unique field/plant record ID generated by the workflow |
| `user_id` | String | Telegram user ID |
| `plant_species` | String | Rice variety/species |
| `location` | String | Field location |
| `area` | Number | Area, usually in rai |
| `water_frequency_days` | Number | Watering frequency in days |
| `last_watered_date` | Date | Last watering date |
| `fertilizer` | String | Fertilizer information |
| `start_date` | Date | Planting start date |
| `end_date` | Date | Estimated end/harvest date |
| `status` | String | Field status |
| `growth_stage` | String | Growth stage in English/internal value |
| `growth_stage_th` | String | Growth stage in Thai display text |
| `harvest_date` | Date | Actual harvest date when available |
| `updated_at` | DateTime | Last workflow update timestamp |

## Sheet: `Plant_Price`

| Column | Type | Notes |
| --- | --- | --- |
| `date` | Date | Price date |
| `rice_type` | String | Rice type/category |
| `price` | Number/String | Reported price |
| `unit` | String | Price unit |
| `source` | String | Data source, for example MOC |
| `updated_at` | DateTime | Last update timestamp |

## Sheet: `Users`

| Column | Type | Notes |
| --- | --- | --- |
| `user_id` | String | Telegram user ID |
| `first_name` | String | Telegram first name |
| `last_name` | String | Telegram last name |
| `username` | String | Telegram username |
| `created_at` | DateTime | First seen timestamp |
| `last_active_at` | DateTime | Last interaction timestamp |

## Optional Sheet: `Price_History`

| Column | Type | Notes |
| --- | --- | --- |
| `date` | Date | Price date |
| `rice_type` | String | Rice type/category |
| `price` | Number/String | Historical price |
| `unit` | String | Price unit |
| `source` | String | Data source |
| `created_at` | DateTime | Record creation timestamp |
